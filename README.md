# Zombie Survival

Zombie Survival is a FiveM resource that transforms your server into a thrilling zombie apocalypse. It features dynamic zombie spawning, realistic combat mechanics, and player health management. The resource is designed for private servers, offering a unique and immersive experience for your friends.

## Install

1. Download the resource from the GitHub repository.
2. Extract the files into your FiveM server's `resources` directory.
3. Add the following line to your `server.cfg` file:
   ```
   start zombie_survival
   ```
4. Restart your FiveM server.

## Use

1. Connect to your FiveM server.
2. Explore the world and avoid the zombies.
3. Use weapons and armor to survive as long as possible.
4. If your health reaches zero, you will be infected and disconnected from the server.
